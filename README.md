# genposed
Easy GUI Docker Compose File Editor built with Next.js  

## Planned features
- Full Compose generation feature
- Github-App to get all the values out of your Application(s) (Goal: Detect all Applications within a Project, MonoRepo Support etc.)
- Coolify API Support (Full API Support)
- Dokploy Support
- Traefik Support
- Caddy Support
- Full Cloudflare Integration (incl. Automatic DNS Setup)
- Multi Compose Detection, so you can Start your "DEV Environment" with a Compose you name (e.g.: compose.local.yml - "Start Dev Environment in UI" (Will be Configurable in UI))

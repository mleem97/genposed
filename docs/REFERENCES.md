# Public references

genposed is an independent project. The following public projects and specifications are useful architectural references. Their licenses and current terms must be checked before copying code.

## Comparable projects

- [Dokploy](https://github.com/Dokploy/dokploy) — Next.js/TypeScript deployment platform, Compose, Traefik, multiple servers, monitoring, and Docker management.
- [Komodo](https://github.com/moghtech/komodo) — control-plane and periphery model, builds, deployments, server inventory, and Compose-oriented automation.
- [Dockge](https://github.com/louislam/dockge) — file-based Compose stack management, reactive command output, and multi-agent support.
- [Portainer](https://github.com/portainer/portainer) — Docker API management for containers, images, volumes, networks, exec, logs, and agents.
- [dyrector.io](https://github.com/dyrector-io/dyrectorio) — self-hosted delivery control plane and agent-based infrastructure communication.
- [Coolify](https://github.com/coollabsio/coolify) — Git-driven self-hosted PaaS workflows, resources, servers, and deployment automation.
- [CapRover](https://github.com/caprover/caprover) — self-service application deployment and operational UX.
